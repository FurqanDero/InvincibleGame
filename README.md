# Invincible: Earth's Last Stand

A 2D side-scrolling brawler built in Unity 6 as a 
first game development project.

## Play it live
[https://invincidero26.itch.io/invincible]

## Built with
- Unity 6 (Universal 2D)
- C#
- Cinemachine
- Unity URP Post-Processing

## Features
- Full player controller with flight mechanics
- 4 combat moves: Punch, Kick, Aerial Slam, Special
- 2 enemy types with Finite State Machine AI
- Parallax scrolling background
- Post-processing effects
- Audio system with SFX and music
- Game Over and restart system

## What I learned
- Unity game architecture
- C# scripting
- Physics-based character controllers
- Enemy AI with FSM
- UI/HUD systems
- Git version control
- WebGL deployment
